# Demo video script (2–3 minutes)

1. Introduce: “AgriTech is a smart farming management web app designed to help farmers keep farm and crop information organised.”
2. Show registration and login.
3. Open dashboard; explain farm/crop counts and quick actions.
4. Add a sample farm such as “Demo Farm”, location “Indore”, soil “Black soil”.
5. Add a sample crop such as “Soybean”, season “Kharif”; change its status.
6. Use the weather card for Indore. Explain that live weather requires an API key.
7. Open Alerts & Advice and explain the reminders are informational.
8. Close with the MERN stack, JWT authentication and MongoDB storage.

Do not show real passwords, API keys, or private farmer data in the recording.
